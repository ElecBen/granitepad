# Changelog

## 0.3.0

- restante(): los segundos que quedan al ritmo actual, o None
- girador(): el marco de la ruedecilla que toca en cada paso
- Los tests corren en GitHub Actions

## 0.2.0

- linea(): la etiqueta, la barra y el porcentaje en una sola linea
- Type hints en la API publica
- Docstring de modulo y __all__

## 0.1.0

- barra(): la barra de progreso entre corchetes
- porcentaje(): el avance en tanto por ciento, ya formateado
- Tests con pytest
